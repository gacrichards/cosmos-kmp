## What I'm building

### 🌌 [Cosmos](https://github.com/gacrichards/cosmos-app)
A NASA media explorer built in Kotlin Multiplatform. Simple in purpose, pristine in execution. Astronomy Picture of the Day, Mars Rover photography, and full-screen media playback — all backed by a shared KMP architecture targeting Android and iOS.

> The starting point for a shared KMP core library that scales across multiple apps.

### ⚽ [Pitch](https://github.com/gacrichards/pitch-app) *(in progress)*
An EPL match center and highlights streaming app. Live standings, fixture results, match timelines, and HLS video highlights — built on the same KMP core modules established in Cosmos.

> A passion project and the second consumer of `kmp-core`, proving the shared module architecture at scale.

### 🧱 [kmp-core](https://github.com/gacrichards/kmp-core) *(emerging from Cosmos)*
A suite of reusable Kotlin Multiplatform modules — networking, domain primitives, caching, and media abstractions — extracted from real app development rather than designed in a vacuum.
